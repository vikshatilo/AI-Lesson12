РОБОЧІ АРКУШІ «ШІ В ПОВСЯКДЕННОМУ ЖИТТІ»

Файли:
- index.html — головна сторінка з переходами до трьох груп;
- group-a.html — ШІ: Здоров'я та режим;
- group-b.html — ШІ: Особистий розвиток;
- group-c.html — ШІ: Професійна комунікація;
- style.css — оформлення всіх сторінок.

Як відкрити:
1. Розпакуйте архів у будь-яку папку.
2. Відкрийте index.html у браузері (Chrome, Edge, Firefox).
3. Оберіть потрібну групу.

Можливості:
- окремі сторінки для кожної групи;
- поля для відповідей і промптів;
- інтерактивні чеклісти аудиту;
- друк або збереження сторінки у PDF через кнопку «Друкувати / зберегти PDF»;
- адаптивне відображення на смартфонах і комп'ютерах.

Сайт працює локально, без сервера та підключення до інтернету.
